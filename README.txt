독서 루틴 NFC 체험 웹페이지
==========================

구성
- 1) NFC 태그 인식 중: 체크 원이 아래에서 차오르는 로딩 + 점(...) 애니메이션
- 2) 루틴 시작 확인: 버튼 pressed 상태
- 3) 타이머: 1초 카운트다운 + 원형 점 이동 + 그라데이션 회전 + 일시정지/완료 pressed 상태
- 4) 완료: '다했어요' + 기록 버튼 pressed 상태
- 5) 에너지 +15: 태양(별) 부유 + '에너지 받기' 클릭 시 캐릭터로 모이는 애니메이션

폰트
- Pretendard 웹폰트를 CDN으로 불러옵니다.
- 네트워크가 끊기면 iPhone 시스템 한글 폰트로 자동 대체됩니다.

전시용 타이머
- 현재는 관람객이 15분을 기다리지 않도록 '15분 루틴의 마지막 20초'부터 시작합니다.
- 그래서 00:20에서 시작하고, 진행점도 왼쪽 끝 가까이에서 움직입니다.
- 실제 15분 전체 타이머로 바꾸려면 app.js의 아래 줄을 수정하세요.
  const DEMO_MODE = true;
  ↓
  const DEMO_MODE = false;

미리보기
- index.html을 바로 열어도 화면을 볼 수 있습니다.
- 브라우저 보안 때문에 로컬 파일에서 일부 기능이 다르게 보이면 폴더에서 간단한 웹서버로 실행하면 됩니다.
- 화면별 검수용 주소: index.html?screen=1 ~ index.html?screen=5

무료 배포 예시 (GitHub Pages)
1. 이 폴더 안 파일 전체를 GitHub 저장소에 업로드
2. 저장소 Settings > Pages
3. Deploy from a branch 선택 후 main / root 저장
4. 생성된 https://...github.io/... 주소를 NFC 태그에 기록

아이폰 NFC
- NFC에는 웹페이지 자체가 아니라 '배포한 URL'을 저장합니다.
- NFC Tools 등의 앱에서 URL 레코드를 Write 하면 됩니다.
- 실제 iPhone Safari에서는 기기 자체 상태바가 표시되므로, 웹페이지 내부의 가짜 9:41 상태바는 자동으로 숨겨집니다.
